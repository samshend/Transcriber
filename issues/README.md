# Issue tracker

This folder is the lightweight repository issue tracker for work that should not get lost between
the macOS and Windows implementation chats.

## Statuses

- `open` — accepted work, not started
- `in progress` — actively being implemented
- `blocked` — cannot proceed without a decision, dependency, or test material
- `done` — implemented and verified

## Adding an issue

Create `NNN-short-title.md` with: problem, evidence, intended behaviour, implementation notes, and
acceptance criteria. Add it to the table above. Keep completed issues in this folder so decisions
and validation remain discoverable.
